ここコード

必要なものを、必要な場所ですぐ出したい。

QRコード、バーコード、Webページ、公式アプリなど「その場所で使うもの」をまとめ、必要な瞬間に素早く呼び出すためのWebアプリです。

ここコードを使ってみる ↗詳しく見る

「持っている」のに、すぐ出せない

会員証や入場券、決済アプリなどはスマートフォンの中に入っていても、必要な瞬間に探すのが意外に面倒です。ここコードで重視したのは、保存することより「今ここで使うものを、すぐ出せること」です。

場所と日付で候補を減らす

項目にはタグだけでなく位置情報や有効期間を設定できます。現地では📍タブを見ることで、その日・その場所に関係する項目を候補として表示できます。

短いタブを分かりやすく

限られた画面では、タブ名を短くしながら意味を伝える必要があります。そこで絵文字の利用を推奨しました。しかし、用途に合う絵文字を探すのが難しい。そこから別のWebアプリ「絵文字ダス」が生まれました。

ここコード → タブに絵文字を使いたい → 適した絵文字を探しにくい → 絵文字ダス

主な特徴

  • QRコード／主要バーコードの読取・登録
  • Webページや公式アプリなどへの導線
  • 複数タグによる分類
  • 検索・お気に入り
  • 日付と位置情報を使った候補表示
  • データのJSON保存・復元
