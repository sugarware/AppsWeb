ここコード

必要なものを、必要な場所ですぐ出したい。

QRコード、バーコード、Webページ、公式アプリ、メモなどを位置情報と結び付け、その場所で必要なものを「今ここ」ですぐ呼び出すためのWebアプリです。

ここコードを使ってみる ↗詳しく見る

「今ここ」で使うものを、すぐ出す

会員証や入場券、決済アプリなどはスマートフォンの中に入っていても、必要な瞬間に探すのが意外に面倒です。ここコードは、保存した情報を単に並べるのではなく、位置情報を使って「今ここで使うもの」を絞り込み、すぐ出せることを重視しています。「ここコード」という名前にも、「今ここ」で使うコードや情報を呼び出す、という意味を込めています。

場所と結び付ける

項目にはタグだけでなく位置情報や有効期間を設定できます。現地では📍タブを見ることで、その日・その場所に関係する項目を候補として表示できます。店、施設、駅、ゴルフ場など、場所が変われば必要な情報も変わる、という考え方がこのアプリの中心です。

その場所で読む「メモ」にも

呼び出す対象はQRコードやバーコード、リンクだけではありません。その場所に着いたときに確認したい注意事項、手順、買う物、施設での覚え書きなど、短いメモも登録できます。「ここに来たら読む」という情報は、位置情報と結び付けることで実用性が大きく上がります。

短いタブを分かりやすく

限られた画面では、タブ名を短くしながら意味を伝える必要があります。そこで絵文字の利用を推奨しました。しかし、用途に合う絵文字を探すのが難しい。そこから別のWebアプリ「絵文字ダス」が生まれました。

ここコード → タブに絵文字を使いたい → 適した絵文字を探しにくい → 絵文字ダス

主な特徴

  • QRコード／主要バーコードの読取・登録
  • Webページや公式アプリなどへの導線
  • その場所で確認するメモの登録
  • 位置情報と有効期間による「今ここ」の候補表示
  • 複数タグによる分類
  • 検索・お気に入り
  • データのJSON保存・復元
